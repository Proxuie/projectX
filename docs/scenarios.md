# Реализованные сценарии и где их проверить

## Обязательный функционал кейса

| № | Требование | Где смотреть | Аккаунт |
|---|---|---|---|
| 1 | Фронт-система в стилистике ФСП, адаптивная | Всё приложение; 360–1440 px | любой |
| 2 | Бэк-система управления процессами | REST API, `docs/api.md` | — |
| 3 | Личные кабинеты четырёх ролей и мультироль | Переключатель ролей в шапке | `multi` |
| 4 | Календарь, заявки, судейские коллегии, протоколы, история | «Календарь» → карточка соревнования | `federation` |
| 5 | Разряды и категории: заявки, присвоение, сроки | «Разряды», «Судьи», кабинеты | `federation`, `athlete` |
| 6 | Реестр и отчёт о численности | «Реестр», «Отчёты» → `.xlsx` | `federation` |
| 7 | Рейтинг и сборная | «Рейтинг», «Сборная» | `federation` |
| 8 | Документы и отчёты | «Отчёты», «Документы» | `federation`, `athlete` |
| 8 | Уведомления (кабинет + письмо) | Колокольчик, `data/mail.log` | любой |
| 9 | Журнал действий и безопасность | «Журнал», согласия при регистрации | `federation` |

## Собственные сценарии

| Решение | Где смотреть |
|---|---|
| Публичная проверка справки по коду | `#/verify/<код>`, ссылка из QR |
| Экспорт реестра в `.xlsx` | «Реестр» → «Экспорт .xlsx» |
| Сводка «Требует внимания» | Дашборд федерации |
| Автопроверка возраста при заявке | «Календарь» спортсмена, бейджи «Вы проходите» |
| Подсветка возможного разряда | «Разряды», таблица кандидатов |
| Контроль сроков по ролям | Дашборд, «Сроки» |
| Привязка тренера с подтверждением | «Профиль» спортсмена, «Мои спортсмены» тренера |

## Быстрые проверки

- **Мультироль:** войти `multi`, переключить роль в шапке — меняются разделы и
  права, повторный вход не нужен.
- **Права:** под `athlete` открыть `#/registry` — будет «Нет доступа».
- **Министерство:** под `ministry` попытка изменить данные отклоняется API.
- **Сроки:** у демо-спортсмена разряд истекает через 20 дней — предупреждение
  видно на дашборде и в разделе «Разряд».
- **Уведомления:** после одобрения заявки и публикации протокола появляются
  записи в кабинете и строки в `data/mail.log`.
